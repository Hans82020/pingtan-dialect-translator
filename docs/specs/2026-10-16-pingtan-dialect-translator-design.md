# 平潭话翻译器 设计文档

- 日期：2026-10-16
- 状态：已与需求方确认
- 项目路径：`d:\work\pingtan-dialect-translator`

## 1. 背景与目标

福州平潭县的方言（平潭话）属闽东语侯官片，与福清话同类，与福州话大体可互通，仅部分发音与音调有出入（平潭话多平声，福州话多去声；音调略有区别）。

目标：做一个**双向语音翻译器**，最终成果在手机端使用。选定形态为 **H5 移动端网页（PWA，零成本方案）**，手机浏览器打开，可添加到主屏幕。

## 2. 需求结论（澄清问答）

| 问题 | 结论 |
|---|---|
| 用户与方向 | **双向**：平潭话 ⇄ 普通话 |
| 语料来源 | AI 整理常用语句库（参考网上福州话/闽东语开源项目），用户后续找人补录音频 |
| MVP 范围 | **完整双向语音对话**（普通话语音→平潭话；方言语音→普通话为实验功能） |
| API 资源 | 无现成 API，采用免费/低成本组合；用户需注册智谱开放平台 + 阿里云百炼免费账号 |
| 形态 | H5 网页（用户明确选择方案二，放弃微信小程序与云开发） |

## 3. 功能定义

### 3.1 核心功能（双向）

| 方向 | 输入 | 输出 |
|---|---|---|
| 普→平 | 说普通话（语音）或打字 | 平潭话汉字写法 + 榕拼/平话字注音 + 声调说明；词库命中句可播放真人录音 |
| 平→普 | 说平潭话（语音，≤30 秒） | 普通话文字 + 语音朗读（实验功能，准确率不保证，界面带"实验"提示） |
| 词库浏览 | 点选场景分类 | 日常问候/吃住/买卖/交通/应急等 150~300 句常用语 |

### 3.2 页面结构（4 页）

```
首页（双向翻译主界面）
 ├─ 大按钮"按住说话" + 方向切换开关
 ├─ 结果卡：平潭话写法 / 注音 / 声调 / 播放按钮 / 复制
 ├─ 文字输入框（录音不可用时降级显示）
词库页（分类浏览 + 搜索）
收藏页（常用句收藏）
设置页（实验功能开关、关于、免责声明）
```

## 4. 技术架构（零成本组合）

```
┌─────────────── 手机浏览器 (HTTPS) ───────────────┐
│  H5 前端：Vue3 + Vite + Vant(移动UI) + PWA        │
│  录音：MediaRecorder（微信内浏览器降级为文字输入） │
└──────────────┬───────────────────────────────────┘
               │ HTTPS API
┌──────────────▼───────────────────────────────────┐
│  云函数 (Vercel Functions 免费层 / 备选 CF Pages)  │
│  ├ /api/translate  → 智谱 GLM-4-Flash（免费）     │
│  ├ /api/audio      → Qwen2-Audio 音频理解（免费额度）│
│  ├ /api/asr        → 百炼 SenseVoice 普通话识别   │
│  └ /api/tts        → Edge TTS 普通话朗读（免费）   │
│  API Key 存环境变量，前端永远接触不到              │
└──────────────────────────────────────────────────┘
静态资源：词库 JSON + 真人录音 mp3（后续补录）
```

- **前端**：Vue3 + Vite + Vant，PWA（manifest + service worker），移动端优先
- **后端**：Vercel Serverless Functions（免费层）；备选 Cloudflare Pages Functions
- **AI 服务**：
  - 自由文本翻译：智谱 GLM-4-Flash（免费）
  - 方言音频理解（平→普）：阿里百炼 Qwen2-Audio（新用户免费额度，之后约几分钱/次）
  - 普通话 ASR：阿里百炼 SenseVoice（便宜、稳定）
  - 普通话 TTS：Edge TTS（免费，云函数代理合成 mp3 返回）
- **运行成本**：0 元起。需要注册：智谱开放平台、阿里云百炼。

## 5. 语料与数据

### 5.1 语料来源（已调研）

| 来源 | 用途 | 获取方式 |
|---|---|---|
| 米时典 SeeDict（seedict.com，20000+ 平话词条，继承榕典数据） | 词典参考、榕拼注音规范 | 页面查询参考，不批量爬取 |
| 平话字表（GitHub: only3km/ciklinbekin） | 字→平话字读音映射 | 直接取用开源码表 |
| LinguaCommons 福州话 Anki 词表（如 nguāi=我、nṳ̄=你、食罢未=吃了吗） | 基础词种子语料 | 公开下载 |
| 平潭县志方言志 / 福清话音系资料（福清话 7 个声调，传统按"平上去入各分阴阳"的八音框架描述；17 声母、46 韵母） | 声调说明与音系文案 | 公开资料摘录 |
| AI 生成常用语句库（150~300 句，按场景分类） | MVP 词库主体 | 本项目整理，需求方找人校对 |

> 注：平潭话语系描述参考平潭县政协文史资料（詹立新说"平潭话"）：属福州语系，与福清话同类略有差别，可与福州话对话，部分发音音调有出入。

### 5.2 词库数据结构（phrases.json）

```json
{
  "id": "greet_001",
  "category": "greeting",
  "zh": "吃了吗？",
  "pt_hanzi": "食罢未？",
  "pt_buc": "Siăh-bà-muôi?",
  "pt_rom": "siah4 ba3 muoi5",
  "tones": "阴入-阴去-阳去",
  "audio": "audio/greet_001.mp3",
  "note": "平潭日常问候语"
}
```

- `audio` 允许为 `null`：未录音时前端只显示注音，录音后补
- 词库构建时打包进前端；另支持一个远程 JSON 地址用于不发版更新词库

### 5.3 AI 翻译策略

1. **词库优先**：普通话输入先与词库精确/模糊匹配（编辑距离），命中直接返回带录音的词条
2. **词库未命中** → GLM-4-Flash 翻译。Prompt 内置：平潭话属闽东语侯官片、近福清话（多平声）、few-shot 词例；要求输出"汉字写法 + 榕拼 + 平话字"
3. 低置信时返回 `confidence: "low"`，前端显示"仅供参考"角标

## 6. 语音交互流程

### 6.1 普→平（普通话语音输入）

```
按住说话 → MediaRecorder 录 webm
  → POST /api/asr（SenseVoice 普通话识别）
  → 普通话文本 → 词库匹配 → 命中：返回词条+录音
                           → 未命中：/api/translate（GLM-4-Flash）
  → 返回结果卡（注音/录音/复制）
```

### 6.2 平→普（方言语音输入，实验功能，设置页可开关）

```
按住说话 → 录音（≤30 秒）→ POST /api/audio
  → Qwen2-Audio（prompt 指明：闽东语福州话平潭口音，转写为普通话）
  → 普通话文本 → /api/tts（Edge TTS）→ 前端播放
```

### 6.3 录音兼容策略

- 依赖 `MediaRecorder`：Chrome/Edge/Android 浏览器/iOS Safari 14.3+ 可用
- 微信/QQ 内置浏览器不支持录音 → 显示引导横幅"右上角 → 在浏览器打开"，自动显示文字输入框（功能不缺失，仅少语音）

## 7. 错误处理

| 场景 | 处理 |
|---|---|
| 麦克风权限拒绝 | 弹提示 + 自动切换文字输入 |
| 录音时长 <1s 或 >30s | 前端拦截，提示重录 |
| API 超时（15s） | 重试 1 次 → 失败显示错误 + 建议改用文字输入 |
| 音频识别失败/乱码 | 返回"没听清，请重说或打字" |
| 免费额度用尽 | 云函数返回特定错误码，前端显示额度提示 |

## 8. 测试策略

- **数据校验脚本**：校验 phrases.json 字段完整性、注音格式、audio 文件存在性
- **API 冒烟测试**：翻译/识别/TTS 各 1 用例的本地调用测试
- **真机测试清单**：iOS Safari、Android Chrome、微信内打开（验证降级）、添加主屏幕 PWA 启动
- **MVP 验收标准**：
  1. 词库 100+ 句可浏览、可搜索
  2. 普通话语音→平潭话注音全流程跑通
  3. 方言语音识别能给出可用的普通话结果（准确率不设硬指标，界面标注实验性）

## 9. 阶段划分

| 阶段 | 内容 |
|---|---|
| Phase 1（MVP） | 词库 + 文字/普通话语音输入 → 平潭话注音输出 |
| Phase 2 | 方言语音识别实验功能（设置页开关） |
| Phase 3 | 录音补录工具 + 词库远程更新 |

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| vercel.app 免费域名国内直连不稳 | 备选 Cloudflare Pages（免费）；或腾讯云托管（月几元钱） |
| 方言识别准确率不可控 | 定位为实验功能、可开关、带免责提示；语料明确"闽东语福州话平潭口音" |
| AI 翻译的平潭话写法可能有误 | 词库优先策略兜底；界面"仅供参考"角标；后续由本地人校对词库 |
| 微信内无法录音 | 自动降级文字输入 + 引导用系统浏览器打开 |
| 免费额度用尽 | 错误码提示；成本上限每次数分钱 |
